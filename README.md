# 数链 Masyu · 一条闭环连过所有珠子

盘上有些格子挂着黑珠或白珠，答案是一条不自交的闭环：它必须经过每一颗珠子，**黑珠那一格必须拐弯、
进出的两格都直穿**，**白珠那一格必须直穿、前后两格里至少有一格拐了**。玩家画的不是格子而是格与格
之间的那条边，一条边三态：没落笔 / 环边 / 排除叉。

这里出货的每一盘都同时满足两件事：**只有一个答案**，而且**能用十条局部规则从空盘一路推到底**——
一次都不许靠猜。两道门都在生成器里，谁都不许替谁兜底：铅笔不知道答案、不回溯；计数器跟铅笔互不
import，连边的几何编码都各写一份。

本文里的数字只有两类来源：仓里读得到的代码（写成 `文件:行号`），和 2026-09-28 早上那一轮全绿跑出来
的读数。跑的命令是 `npm test`（四套：规则表 67 条断言、推理逐结论对账、计数器与朴素枚举对账、出货
探针）、`SAMPLES=24 node tools/balance.mjs`、`bash tools/verify.sh`，环境 Node v26.8.1 / macOS 26.6.2 /
Apple arm64 15 核。引擎断言、难度实测表、浏览器门禁都是当场重跑的；**墙钟那一列带争用**：跑 balance
那一阵本机 load average 30（两个隔壁会话遗留的 node 进程在吃 CPU），所以绝对毫秒只当上界看，
分数/步数/出货率是纯计算口径不受影响。

**代码 > 本文档**：本文与 `js/`、`tools/` 冲突时，以代码和它跑出来的输出为准。

## 规则（玩家视角）

侧栏那三条就是规则本体（`index.html:101-105`），判胜逐条对得上引擎谓词（`js/engine/pencil.js:596` 的
`verify`）：

1. **黑珠**：那一格的两条环边成直角，并且进出那两格都直穿过去——`black-turn` / `black-straight`。
2. **白珠**：那一格的两条环边成一条直线，并且前后两格里至少一格拐了——`white-straight` / `white-turn`。
3. **一条环**：每个环上的格恰好两条环边，不许分段、不许提前闭死——`cell-degree-two` / `single-loop`。

- 玩家落笔的唯一入口是 `Game.setEdge`（`js/ui/game.js:53`）：三条路（拖拽 `js/main.js:276`、右键画叉
  `:287-291`、键盘 `:333`）和提示都从它过，所以撤销栈和步数记的就是玩家干的活，没有旁路。
- **判胜只有一处**：`Game.status()`（`js/ui/game.js:182`）把玩家画下的环边交给 `verify()`，没画的地方
  一律补成「不在环上」。玩家自己标的叉和补出来的叉是同一种东西，所以多画一个叉不可能改变结论——
  UI 侧长不出第二块记分板。侧栏「引擎说」那一格写的就是 `verify()` 的返回值（`js/main.js:117-119`）。
- 合法定义只有一份：页面判胜、生成器两道门、测试台问的都是 `pencil.js` 的 `verify` 与 `counter.js` 的
  `satisfies`（后者是题面文字的第三种写法，两套不一致就是 bug，`tools/counter-test.mjs` 就是来抓这个的）。

## 怎么玩

- 菜单五档：6×6、7×7、8×8、9×9、10×10（`js/engine/generate.js:30` 的 `SIZES`，下拉框就是遍历它，
  `js/main.js:479`）；默认 6×6（`js/main.js:21`）。`SIZE_TABLE` 里另外三个长方形（7×6、8×7、10×9）
  **不进菜单**，只当难度表的对照组量（见「难度是量出来的」）。10×10 以上本轮没量过——别把"没测"读成"能出"。
- 「换一局」真的换一局：seed 由 `crypto.getRandomValues` 现造（`js/main.js:69-75`），**不是日期函数**；
  随机只发生在选 seed 这一步，生成器内部一点随机都没有（同一个 seed 在任何一台机器上画同一张盘）。
  界面上没有 seed 输入框，也没有「按日课全世界同一盘」——这一仓没做，别说。
- 落子：拖拽相邻两格连环段，右键把指针压着的那条边画成排除叉（再点一次擦回没落笔），三支笔
  画环／排除叉／擦掉，`E` 轮着切；`方向键` 移光标、`回车` 从锚点动手、`退格` 擦光标格、`H` 提示、
  `Z` 撤销、`N` 换一局（`index.html:116`，实现在 `js/main.js:371-443` 的 `keydown`）。一次拖拽算一条撤销记录
  （`beginGesture`/`endGesture`，`js/ui/game.js:89-100`），撤销和全清也各记一步。
- 提示走的是**出题时那同一条铅笔通道**（`js/main.js:166-199`）：`nextDeduction` 只有三种回话——被迫结论 /
  盘自己打脸 / 推不动了，代码里就只有三个分支，**没有第四支「那提示替你猜一个」**。它落的那一笔仍然经
  `Game.setEdgeById` 进撤销栈、在步数上记一步（所以门禁数得出、玩家撤得掉）；推不动时它就说推不动。
- 存档只有一个键 `masyu.save.v1`（`js/store.js:12`），存的是原始 seed + 尺寸 + 每条边一个字符
  （`'0'/'1'/'2'`，`js/ui/game.js:17`）+ 步数 + 耗时，几百字节：盘面从不经过存储搬运，恢复就是拿 seed
  重算一遍再逐边贴上笔迹（`Game.decode`，`js/ui/game.js:204`）。

## 这六条承诺，每一条怎么变成一条会红的命令

| 承诺 | 怎么检查 |
|---|---|
| **唯一解**：端出来的每一盘，独立穷举器在预算内数出来就是 1 个解 | 生成器门 0（`js/engine/generate.js:122-132`）拿**全部合法放珠位置**当题面问 `countLoops`，不是 UNIQUE 就整条环丢掉；挖珠时每摘一颗再问一遍（`:215`）。`npm run balance` 的 proven 红线拿**本轮出货的盘**独立复算（`solveWithRules` + `verify` + `countLoops`），本轮读数：八档 ×32 = 256 盘，非 UNIQUE 0、verify 不过 0、铅笔没推到底 0 |
| **零猜测**：出货的每一盘都能用那十条从空盘推到底，一次都不许回头猜 | 门 1（`js/engine/generate.js:133-136`）与铅笔规则表（`js/engine/pencil.js:532` 的 `RULE_ORDER`）。`tools/pencil-test.mjs` 逐结论对账 7403 条结论，**推错了 = 0**；balance 每档「零猜测可解率」本轮 100%（256/256） |
| **提示只给下一步可证的事实**，并且说清凭哪条规则 | 提示的唯一来源就是 `nextDeduction`，`RULE_TEXT` 那句原文跟着结论一起上屏（`js/main.js:193`）；`tools/scenarios.js` 的 hint 场景在真实 Chrome 里量 18 项（含「提示落的每一笔都进步数和撤销栈」「推不动时不落笔也不装成落了一笔」） |
| **难度是量出来的**，不是作者的感觉 | `SAMPLES=32 node tools/balance.mjs`：八档全出货、零猜测 100%、score p50 沿菜单不降且首末两档支配概率 ≥ 0.85（本轮 1.000）、每档墙钟 p95 有红线。红了就 `exit 1` |
| **每颗珠子都删不得**（单颗删除意义上的极小）：端出来的每一盘，摘掉任意一颗珠子这题就不再是题 | 门 2（`js/engine/generate.js:143-145`）：挖珠时如果一颗珠子撞了计数器预算——那颗珠子是"预算逼着留下的"，既没证必要也没证可删——**整条环作废重抽**，那颗珠子不留在盘上冒充证据。`npm run balance` 的 minimal 红线不读引擎的账，而是把端出去那一盘在**最终盘面**上逐颗重摘复算（`tools/balance.mjs` 的 `auditMinimality`）：摘得掉 = 这颗不必要、超预算数不完 = 这颗没证据，出现一颗就红。本轮读数：八档 ×32 = 256 盘，摘得掉 0 颗、没证据 0 颗、三本账 256/256 轧平 |
| **续局只续"真的是那一局"的局**：刷新页面接着画，前提是存档里那张盘和现在重画出来的是同一张 | 存档存的是原始 seed（`js/store.js:58-69`），而 seed→题面 只在**同一版生成器**里稳定——本轮加的门 2 就是这样一个改版。boot 先 `pendingResume()` 只看形状，再拿重画出来的指纹向 `Store.resume(指纹)` 对一次账（`js/main.js:233`、`js/store.js:80-98`）：对不上 ⇒ 一颗旧笔迹都不搬、那份存档就地作废、并且当着玩家说"这一局重新开始"。浏览器闸拿**另一张盘的指纹**冒充旧版生成器画出来的盘走这条路（`tools/scenarios.js:748-770`，resume 那场 13 项：笔迹全空、步数归零、状态行有话、废存档换成了写着当下指纹的诚实一份） |
**这两条闸真的咬得住**：`balance.mjs` 带两个可复现的剂量，一个是摘指定那一盘的一颗珠子
（`--dose=<sizeKey>#<样本号>`，破的是挖珠不变式，不是随机运气），一个是把门 2 整个关掉
（`--dose=minimal`，退回"超预算就把那颗珠子放回去"）。2026-09-28 晚在同一份代码上各跑一遍
（默认 `SAMPLES=24`，同一批 seed，未被变异的那七档就是当轮的对照）：

```
node tools/balance.mjs --dose=10x10#11  → RESULT ok=false，红线 3 项，全部指名 10x10 那一盘
   [DOSE] 变异已落地：10x10#11 摘掉第 1 格（原值 2）
   - 10x10 有 1 盘 verify 不过
   - 10x10 有 1 盘独立复算不是预算内 UNIQUE
   - 10x10 steps ≠ 盘上边数（每步定一条边的不变式被打破）
   其余七档 + 10x10 的另外 23 盘：出货率、零猜测、proven、minimal 照旧全绿

node tools/balance.mjs --dose=minimal   → RESULT ok=false，红线 2 项
   [DOSE] 门 2 已关掉（strictMinimal:false）⇒ 生成器退回"超预算就把那颗珠子放回去"
   - 9x9 有 1/24 盘的珠子没证过删不得（独立重摘复算：摘得掉 0 颗、超预算无数 6 颗，盘 #22）
   - 10x10 有 5/24 盘的珠子没证过删不得（独立重摘复算：摘得掉 0 颗、超预算无数 11 颗，盘 #11,#12,#14,#19,#20）
   对照档同样漏出来（8x7 1 颗、10x9 6 颗，非菜单档只披露不判红 ⇒ 整张梯子 24 颗）；
   而八档出货率 24/24、零猜测 100%、三本账逐盘轧平（它是红线，没进红线汇总就是轧平了）——
   **这些全绿的读数码不住那 24 颗没证据的珠子**，只有 minimal 这一条看得见它们
```

红了就指名道姓哪一档哪一盘——「绿着」不等于「拦得住」，每条承诺都得有这样一次 A/B。

## 这个仓**不承诺**什么

- **不承诺「唯一解 ⟹ 铅笔推得完」**。十条规则不完备，反方向不成立：`tools/pencil-test.mjs` 拿出货盘
  逐边摘稀，192 组里有 **174 组推不动**——那正是生成器要丢掉的形状，不是漏网的答案。
- **不承诺「线索最少」**。极简性只到**单颗删除**这一层：每颗珠子都当场证过"摘掉就不再是题"，
  但没有哪条红线说这副线索是同类里最稀的——那要另一套搜索。为了守住上一行那句承诺，代价搬到了
  出题侧：挖珠撞计数器预算 ⇒ 整条环作废重抽（`js/engine/generate.js:143-145`），本轮 256 盘里有
  21 条环死在这道上（8×7 1 盘、9×9 2 盘、10×9 6 盘、10×10 8 盘各挨过至少一次），它只花重试次数，
  端出来的盘上一颗"没证据的珠子"都没有。
- **不承诺墙钟**。`makePuzzle` 是同步的、不可中断（`js/main.js:207-220` 只在开头让出一帧好让「生成中」画得出来），
  所以毫秒数是这台机器的读数，不是对玩家的等待承诺；要兜底得先把出题挪进 worker。
- **不承诺 `no-2x2-square`（`RULE_ORDER` 里排第八那一条）有用**。它在 192 张出货盘的整条铅笔序列里
  **一次都没命中**；拿 24 张 8×8 逐步查前件（某个 2×2 已有三条环边、第四条还没定），2688 步里
  **前件成立 0 次**——不是被别的规则抢了，是这些盘上根本不出这个形状。它在 `rule-test` 里测得动
  （发 2 / contra 1 / 静 3），那是构造盘。所以「十条规则」在出货盘上实际只用九条。
- **推理室（`js/main.js:499` 的 `window.masyu`）是给门禁用的**，不是给玩家的控制台：场景打的是页面
  加载的那张模块图，所以浏览器绿一次等于页面那侧的引擎绿一次。

同一批代码之前用 `SAMPLES=24` 量过（2026-09-28 08:02，门 2 还没上），那张表 10×10 的墙钟是
497 / 4841 / 5687 ms——**争用机上的上界**，别拿它当 SLA；上面这组是门 2 落地后重测的。

- **分数是 `tools/balance.mjs` 自定义的度量，引擎里没有 `scoreOf`**：唯一证据源是 `solveWithRules` 从空盘
  推到唯一解的规则命中，权重 = 用这条规则要"看多远"（只看本格 1 / 珠子四邻 2~3 / 2×2 4 / 整圈整块 5）。
  门槛里的「支配概率」是 Mann-Whitney U 换算的 AUC：菜单首末两档 P(10×10 分数 > 6×6) = 1.000（门槛 0.85）。
- **`steps` 恒等于盘上边数**（每步恰好定一条边，`js/engine/pencil.js:589`/`:661`），所以它只量尺寸：
  6×6 永远 60、10×10 永远 180。**任何按"推理步数"写的难度说法在本引擎里等于按格数说话**，别用。
  难度的区分力全在分数的权重混合里（score/steps ≈ 2.4，八档都一样）。
- **这些是总体口径**：p50/p95 是 24 个样本的分位数，不是"你手上这一盘"的难度。同一档里的分数带宽
  （6×6 [127..157] vs 10×10 [407..468]）不重叠，但档位**内部**没有分级。
- 每次出货盘的规则命中都带「最大贡献者占多少」：聚合命中率可以全部来自一个退化样本，只看聚合数的
  报告都欠这一列（`balance.mjs` 每个 size 都打）。

## 跑测试

- `npm run check` —— 每个 `js/`、`tools/` 文件过一遍 `node --check`，`bash -n tools/verify.sh`。
- `npm test` —— 四套纯 Node，不用浏览器就能挡合并：
  - `tools/rule-test.mjs` **67 条断言**：每条规则要 fire（该发的 case 带上预期的边和值）、要 contra（矛盾形态）、
    而且要**静得住**（near-miss 必须闷——逢发必挂的规则没有选择性）。
  - `tools/pencil-test.mjs` 6×6/8×8 ×8 盘 = 16 盘：逐结论对账 224 次推演 / 7403 条结论、**推错 0**；
    出货盘 `solveWithRules` solved 16/16；单边改动喂 1376 条、`verify` 拒掉 1376 条；2×2 翻边 592 条，
    `verify` 与 `counter.satisfies` 意见一致 592 条。
  - `tools/counter-test.mjs` 五节：① `countLoops` vs **朴素枚举**（朴素当裁判）14 个配置逐一对账，其中
    10 个配置解数 >1（"说 MULTIPLE 的能力"也被量到了）；② 门 0 丢掉的环必须 count>1；③ 出货盘逐盘 UNIQUE；
    ④ 重放挖珠序列，每摘一颗同时问铅笔和计数器；⑤ 把预算压到 2000，真实 10×10 候选确实 OVERBUDGET，
    流水线**只丢不出货**（两个预算档 ×3 盘共 6 次 `makePuzzle`：出货 3、no-loop 3、`overbudgetFull` 累计 7、
    `dropByOverbudget` 累计 10，出货盘里"预算外唯一性"违规 0）。
  - `tools/generator-probe.mjs` 默认五档菜单 ×8 盘（2026-09-28 20:59 实测 7.2 秒）：三个"只该为 0"的项必须
    真的是 0（`illegalLoop` 参考环自己不合法 = `loop.js` 写错、`refRejected` 参考环过不了自己的
    `satisfies` = 两边有一边写错、`dropByMismatch` 铅笔推完却定出另一个环 = 铅笔不 sound），且全部出货；
    ④ 那一节量的是**版本护栏**：同一个 seed 重画两次必须是同一张盘（指纹逐字节相同），而指纹对不上时
    `Store.resume()` 要返回 null、把那份存档就地清掉、并把原因写进 `resumeDiscarded`（"没有指纹"和
    "指纹不一致"分两种，两种都要验）。
- `npm run doctest` —— **文档数字闸（18 组 / 233 项）**：README/DESIGN 里每一个代码能算出来的数（档位/键数/断言数/规则条数/权重/端口/难度表逐格/带宽/引用行号）都现场拿引擎与 `rule-test`/`pencil-test`/`counter-test`/`generator-probe`/`balance` 重算一遍再对表，期望值只取代码不取文档，文档抄错就在这里红。
  - 引用分两层，这一轮各收紧一次。**D10**（文档里「名字 + 行号」同现的那些）判"那个名字现在还坐在被指的那几行里吗"，
    口径是**整词**：子串口径比它替掉的手抄表更弱 —— `createState` 所在的那几行里 `createStat` 也算"在"，真漂移读得出绿。
    名字形状走整词，短语与选择器形状仍走 `includes`（它们本来就不是标识符），两处口径不同是设计不是漏。
    **D11**（文档里每一条 `path:NN` / `path:NN-MM`）以前只问文件在不在、行号越不越界，现在多问第三样：
    **被指的那几行不许整段是空白** —— 在前面插几行之后 `:NN` 指的是隔壁的空行，可它照样在界内；在界内不等于指到了代码。
  - 两道的刀都不新增项数：D10a 自己带一把"截前缀"的刀（现量靶子是某条真引用里"子串在、整词不在"的那个名字），

## 技术形态

浏览器原生 ES 模块，运行时零依赖（`package.json` 里只有 devDependencies 的 Electron），单 `<canvas>` 绘制
（`js/render/board.js`），`server.cjs` 是本地静态服务器，`electron/` 是同一份代码的桌面壳。
拷进 artifact 的清单只有一份，住在 `tools/assemble-site.sh`（`pages.yml` 与本地部署集闸调同一支，workflow 里不再手抄 `cp` 行）。站点里现在是：`css` `icons` `index.html` `js` `manifest.webmanifest` `sw.js`——`tools/` 不进站点。这一仓**没有 golden 夹具**
（`tools/` 里没有冻结的答案边集，翻遍也没有），场景全部拿 seed 在页面里现出题再验（如
`tools/scenarios.js:241` 的 `newGame({seed:'gate-render-6', sizeKey:'6x6'})`），所以线上根本没有"答案"这个
东西可泄漏。

## 上线的到底是哪一批文件

这个仓没有打包器：站点=一次文件拷贝。以前「拷哪些」写在 `pages.yml` 的 `run:` 里（手抄的几行
`cp`）。本地 `index.html` 直读仓库根，永远自洽；线上却按那份清单拷，于是页面后来引用的
`manifest.webmanifest`、`sw.js`、`icons/*` 可能一个都没上去——线上 404，而仓里的引擎测试与
真浏览器闸全绿，因为它们跑的都是仓库根，没有任何一步在「按清单拷」的那个环境下加载过页面。

现在清单只有一份，住在 `tools/assemble-site.sh`：CI 调它拷 `_site`，本地闸调它拷临时目录，
然后**对拷出来的产物**提要求（`tools/deploy-set.mjs`）：

- **W 清单与页面同源**：`pages.yml` 里必须真有 `run: bash tools/assemble-site.sh <dir>` 这一行，
  `ci.yml` 里必须真有 `run: node tools/deploy-set.mjs`。认的是调用那一行，不是文件里出现过这个
  路径——注释里本来就会写它，只 grep 字符串会被一句散文喂绿。
- **R 引用可达**：引用不靠手打名单。从 `index.html` 的 `href/src` 出发，凡解析出来是 `.js`/`.css`
  的就把那一站也扫一遍（CSS 的 `url()`、JS 去掉注释后的 `'./…'` 字面量、`new URL(x, base)` 的两种
  基、`navigator.serviceWorker.register`、`scope`），`manifest` 的 icons/screenshots/shortcuts 各自
  的 `src` 也算引用。取径上读不到的那一站本身就是红（读不到＝这一站根本没扫）。每条引用都必须在
  产物里且非 0 字节；绝对路径单列一条红，因为 Pages 挂在 `/<repo>/` 前缀下会跳出去。
- **P 位图不许说谎**：`manifest` 声明的 `sizes` 必须等于 PNG IHDR 的真实宽高——文件图标读文件头，
  内联成 base64 的图标先解码再读同一段。后一条不是可选项：图标可能住在清单里而不是盘上的 `.png`
  （有的仓另有一条"零二进制文件"的承诺，那条只约束"有没有 .png 这个文件"）；如果 P 段只筛文件名，
  声明写 512 而真图 192 就一路放行。
- **钉住两个数**：R 段实际检查的路径条数（`30`）与这一次跑的断言条数（`48`），两个数
  都钉在 `tools/deploy-set.mjs` 顶部的那对常量里。没改页面却掉了，说明解析断了；删掉一张图标会同时
  少一条 R10 与那张的 P1/P2，所以两个数一起钉，断言条数能漂就是闸在缩水的信号。这一节故意只写数值、
  不写那对常量的名字，也不写别仓文档闸的编号：有的仓的文档闸会拿"文档里出现过的同名标识号"回数它
  自己的条数，还有的会把文档里点到的每个组编号逐个核对"这一轮真的发过"——两道闸共用一个名字，
  或者在本仓的文档里出现一个本仓没有的组编号，打红的都是不相干的那一边。

`tools/deploy-set-selftest.mjs` 是这两颗钉的阳性证明：它把仓库复制到临时目录，照着每一类断言
各下一刀（X1 清单不收位图目录 / X2 模块边改名 / X3 CSS 写绝对路径 / X4 `start_url` 绝对 /
X5 删光 >=512 图标 / X6 少一个必填字段 / X7 声明尺寸与真图不符 / X8 workflow 不调脚本 /
X9 CI 不跑闸 / X10 是阴性对照——往入口 JS 追加一行只写在注释里的假路径，闸必须仍然绿、条数仍然
`30`、断言仍然 `48`；X11 og:image 退回相对路径 / X12 og:image 的前缀指向别的 slug /
X13 内联位图谎报尺寸——只在有靶子时下：X11/X12 要页面上那句 og:image，X13 要清单里真有一段 base64
图标，没有就打印 SKIP；反过来 X1 没有位图目录可砍时改砍 css，P 段一位都不核时台架直接报靶子不够），
要求每一刀都让闸**点名**变红。靶子从 `DEPLOY_SET_DUMP=1`
的出处表现挑（取径真的会读的那支 JS / 那一张 CSS，不写死某一个仓的入口名），所以页面改了、仓与仓
不同，台架跟着走。

`node tools/deploy-set.mjs` 与 `node tools/deploy-set-selftest.mjs` 就是 CI 跑的那两条命令本身
（package.json 里的 `deploy-set` / `deploy-set:selftest` 只是同一支脚本的 npm 入口）；本仓的整闸在 `tools/verify.sh` 的 `=== deploy-set ===` 那一段也各跑一次。它们红的时候并进本仓那条出口的退出码——这一条是这么证的：
把 ci.yml 里那行 `run: node tools/deploy-set.mjs` 砍掉，本仓整闸必须点名红且退出码非 0。
所以「本地全绿、线上 404 自己的 manifest / sw.js / 图标」这一类坏法在本地就会红。
